# Getting help

- **Read the docs first.** The [README](README.md) has a FAQ. [docs/CONFIGURATION.md](docs/CONFIGURATION.md) explains
  every setting and how to connect OpenAI, OpenRouter, Gemini, Ollama, LM Studio, vLLM and other OpenAI-compatible
  endpoints.
- **Questions and setup help:** use
  [GitHub Discussions](https://github.com/ducdt1298/panelingo/discussions). It is also the place to
  share which models work well for which languages.
- **Bugs and site problems:** open an issue with the
  [bug report form](https://github.com/ducdt1298/panelingo/issues/new/choose).
- **Feature ideas:** check the [roadmap](docs/ROADMAP.md), then open a feature request.
- **Security issues:** report them privately as described in [SECURITY.md](SECURITY.md), never in a public issue.

When asking for help, include the extension version (popup footer or `chrome://extensions`), your Chrome version, the
provider and model you use, and the error text shown in the popup or on the image. **Never post your API key.**

This is a community project maintained in spare time. If it saves you time, consider
[supporting it](README.md#support-the-project).
